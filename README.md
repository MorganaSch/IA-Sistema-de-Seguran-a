## 📋 Sobre o Projeto

**AI Video Segurança** é uma aplicação web interativa que utiliza aprendizado de máquina para reconhecimento de objetos em tempo real a partir de vídeos. Com o poder da biblioteca **ml5.js** e **p5.js**, a aplicação é capaz de identificar e contar objetos em uma transmissão de vídeo ao vivo. Esta solução é ideal para quem deseja explorar como a inteligência artificial pode ser aplicada na vigilância e análise de vídeos, além de ser uma ótima introdução ao reconhecimento de objetos utilizando redes neurais.

## ✨ Funcionalidades

- 🎥 **Reconhecimento de Objetos em Vídeos:**  
  O sistema usa uma câmera ao vivo para identificar objetos no vídeo em tempo real.

- 🔢 **Contagem de Objetos:**  
  Exibe a quantidade de objetos detectados no vídeo em tempo real.

- 🚀 **Interface Interativa:**  
  Com um botão para iniciar a detecção e exibição do status de reconhecimento.

- 🌐 **Design Responsivo:**  
  A interface adapta-se a diferentes tamanhos de tela, proporcionando uma experiência otimizada para dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estruturação da página.
- **CSS3** - Estilo e design da aplicação.
- **JavaScript (p5.js)** - Manipulação do vídeo ao vivo e integração com aprendizado de máquina.
- **ml5.js** - Biblioteca para realizar o reconhecimento de objetos.
- **Bootstrap** - Framework CSS para design responsivo.
